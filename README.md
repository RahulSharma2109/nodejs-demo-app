\# Node.js Demo App — CI/CD Pipeline



\## Objective

Automate testing and Docker image publishing using GitHub Actions.



\## Tools

\- Node.js

\- Git and GitHub

\- GitHub Actions

\- Docker

\- Docker Hub



\## Application Endpoints



| Endpoint | Purpose |

|---|---|

| `/` | Returns the welcome message |

| `/health` | Reports application health |

| Other routes | Return HTTP 404 |



\## Run Locally



```bash

npm install

npm test

npm run build

npm start
